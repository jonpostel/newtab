# NEBULA TAB — 深色新标签页

一款简洁的 Chrome 新标签页扩展，用你自己的常用网站代替默认起始页。深色主题，无花哨特效，支持中英双语自动切换。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本项目文件夹
4. 打开一个新标签页，即可看到 NEBULA TAB

> 也可以在扩展列表里把它固定到工具栏，方便管理。

## 使用

### 添加快捷方式

- 点击右下角橙色 **+** 按钮
- 填写名称、网址（图标 URL 可选，留空会自动获取网站图标）
- 点击「保存」

### 编辑 / 删除

- 鼠标悬停在卡片上，右上角会出现三个按钮：
  - **铅笔** — 编辑该快捷方式
  - **网格点** — 长按拖动调整顺序
  - **叉号** — 删除该快捷方式

### 搜索

- 顶部搜索框输入关键词，可按名称或域名实时筛选卡片
- 清空搜索框即可恢复全部

### 调整顺序

- 悬停卡片，按住右上角的**网格点**按钮拖动到目标位置即可

### 备份与导入

- **备份**：点击右下角上传图标按钮，会下载一个 JSON 备份文件
- **导入**：点击右下角下载图标按钮，选择之前的备份文件，确认后覆盖当前数据

> 备份文件包含全部快捷方式，可在不同设备或浏览器间迁移。

## 语言

界面会根据浏览器语言自动切换中文 / English，无需手动设置。

## 常见问题

**新标签页没变成 NEBULA TAB？**
确认扩展已启用，并在 `chrome://extensions` 中没有报错。若仍无效，重启浏览器再试。

**网站图标不显示？**
图标依赖网络获取，离线或网站无 favicon 时会显示名称首字母作为占位，属正常现象。

**数据存在哪里？**
所有快捷方式保存在浏览器本地，并经过加密存储，不会上传到任何服务器。
